# 🚀 Personal Developer Portfolio | Raghav Gupta

A modern, high-performance, and visually engaging personal developer portfolio engineered with clean HTML5, CSS3, and JavaScript. Styled with a dark glassmorphic UI, ambient radial background glows, FontAwesome icons, and multi-category dynamic project filtering.

🌐 **Live Website:** [https://raghav12344.github.io](https://raghav12344.github.io)

---

## 🌟 Key Features

- **💎 Glassmorphism UI:** Built with translucent backdrop filters, smooth hover animations, and subtle gradient glowing elements.
- **⚡ Multi-Category Project Filtering:** Filter featured work (*AI / ML, Web Development, Java Desktop, DSA*) smoothly without page reloads using lightweight Vanilla JavaScript.
- **🏆 Achievements & Coding Profiles:** Highlights national competitive exam ranks (**JEE Main 99.83%ile**, **JEE Advanced AIR 7406**), **400+ solved DSA problems**, and direct links to LeetCode, Codeforces, Naukri Code360, and GeeksforGeeks.
- **🎓 Complete Academic Timeline:** Showcases B.Tech CSE at **MNNIT Allahabad** (`CPI: 7.69`) alongside Class XII (`87.8%`) and Class X (`95.0%`) academic milestones.
- **📱 Fully Responsive Layout:** Designed mobile-first using CSS Grid and Flexbox to ensure crisp rendering across all viewports.
- **🟢 Active Status Badge:** Features a live animated CSS pulse badge highlighting job search availability.
- **🚀 Zero Framework Overhead:** Fast load times with zero heavy JavaScript frameworks—built purely on web standards.
