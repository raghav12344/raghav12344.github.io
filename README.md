# 🚀 Personal Developer Portfolio | Raghav Gupta

A modern, high-performance, and visually engaging personal developer portfolio engineered with clean HTML5, CSS3, and JavaScript. Styled with a dark glassmorphic UI, ambient radial background glows, FontAwesome icons, and dynamic project category filtering.

🌐 **Live Website:** [https://raghav12344.github.io](https://raghav12344.github.io)

---

## 🌟 Key Features

- **💎 Glassmorphism UI:** Built with translucent backdrop filters, smooth hover animations, and subtle gradient glowing elements.
- **⚡ Dynamic Project Filtering:** Filter featured projects (*AI / ML, Web Development, Java Desktop*) smoothly without page reloads using lightweight Vanilla JavaScript.
- **📱 Fully Responsive Layout:** Designed mobile-first using CSS Grid and Flexbox to ensure crisp rendering across all viewports.
- **🟢 Active Status Badge:** Features a live animated CSS pulse badge highlighting job search availability.
- **🚀 Zero Framework Overhead:** Fast load times with zero heavy JavaScript frameworks—built purely on web standards.

---

## 🛠️ Tech Stack

- **Markup:** HTML5
- **Styling:** CSS3 (Variables, Flexbox, Grid, Glassmorphism, Keyframe Animations)
- **Scripting:** JavaScript (ES6+ Vanilla JS)
- **Typography & Icons:** [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) & [FontAwesome 6](https://fontawesome.com/)
- **Hosting & Deployment:** GitHub Pages
